Check Property — Editable Scenario Bar

Current scenario bar is read-only (left). Proposed: tap to edit inline, re-run without losing the property (right).

Why this change?

The scenario lock bar (budget / down payment / rate) is the most important input on this page — it controls all the affordability math. Today it's completely read-only after the initial submit. If a user wants to try "what if I put 10% down instead of 20%?" they have to navigate back, change the scenario, and wait for the property to re-load. This kills the entire "try different scenarios" use case. The proposed change makes the bar tappable — it expands into an inline editor that re-runs the numbers on the same property without navigation. Also adds a mobile accordion pattern for the 5 result sections to reduce scroll.

"✎ Edit" button in the scenario bar — expands the bar into a 3-field inline editor (price, down %, rate). Re-runs all math on the current property without navigation.
Down payment as dropdown — shows common options (20%, 10%, 5%, FHA 3.5%, VA 0%) with the dollar amount calculated automatically. Reduces typing friction.
Accordion sections — Gap Analysis and PITI open by default. Cash to Close and True Cost collapsed. User expands what they need. Reduces mobile scroll by ~60%.
Summary stats always visible — List Price, Redfin AVM, PITI, AVM vs Ask are pinned above the accordion. User always sees the 4 key numbers without expanding anything.
