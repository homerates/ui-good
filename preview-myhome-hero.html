My Home — Hero Section Redesign

Current hero (left) vs proposed hero (right). Scroll down for the stats grid relocation.

Why this change?

The current hero stacks 7 distinct UI layers before the user even reaches the tab navigation: photo, details bar, 4-stat grid, equity bar, rate watch input, CTA buttons, then chips. On mobile this is 600px of scroll before seeing any analysis content. More critically, all 4 stats are displayed at equal visual weight — users don't know what to focus on. The proposed redesign collapses the hero to 3 elements: photo, ONE headline number, one supporting metric. Everything else moves into the first tab (Equity & Value) where it belongs.

Rate watch embedded in hero — an alert-setting input competes visually with the equity bar and CTAs. Wrong location for a secondary action.
